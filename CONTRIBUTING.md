# Contribuir a AlojaU

## Flujo
1. `git checkout develop && git pull`
2. `git checkout -b feature/HU-00X-slug`
3. Commits: `feat(HU-001): ...`
4. `git push -u origin feature/HU-00X`
5. PR a `develop` + 2 capturas + DoD 6 puntos

## IA responsable
- Bitácora en PR + 4 controles (fuente, ejecución, lectura, decisión humana)
- Pesos índice 40+20+15+15+10 y estados PENDIENTE→ACTIVO son decisiones humanas, no IA
