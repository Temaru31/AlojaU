# Cómo funciona AlojaU

AlojaU es una plataforma de vivienda universitaria para estudiantes de Popayán, Colombia. Publica arrendadores (propietarios) y buscan estudiantes.

Flujo básico: Buscar (por campus o ciudad) → Filtrar (precio, tipo, servicios) → Comprender (detalle con fotos, servicios, reglas y ubicación referencial) → Confiar (índice de confianza) → Contactar (WhatsApp del propietario desde el detalle).

Solo se muestran publicaciones en estado ACTIVO, es decir, aprobadas por moderación y vigentes. Las pendientes de revisión, rechazadas o pausadas no son visibles para estudiantes.

Si una publicación pierde vigencia (30 días sin renovar) deja de aparecer hasta que el propietario la renueve. Las marcadas como desactualizadas llevan tiempo sin actualizarse: verifica los datos con el propietario.
